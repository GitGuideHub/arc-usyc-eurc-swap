# USYC ↔ EURC Swap on ARC Testnet

This repository contains smart contracts and instructions for deploying a minimal Swap contract on the ARC Testnet using USYC and EURC tokens.

## ✔ Swap Contract Features
- Swap USYC → EURC  
- Swap EURC → USYC  
- Owner can fund the contract  
- Owner can withdraw liquidity
